# 信息爆炸思1
 
1. 信息≠技能，技能≠变现：二者是两道鸿沟，信息只是基础，需经训练内化成技能，技能也未必能直接转化为收益。
2. 知识是指引，实践出真能：知识仅帮人少走弯路，真正能力要靠亲身实践、体感积累，无法单靠书本获得。
3. 信息差永远存在：知识是过去总结，社会持续变化，一手信息掌握在开拓者手中，大众获取的多是过时、贬值的信息。
4. 易得知识价值有限：海量免费知识多仅作史料、闲聊谈资或写作素材，难创造实际价值。
5. 警惕认知错觉：碎片化信息易让人误以为认知很高，实则脱离实干，易归咎于外部因素，忽视自身行动不足。
6. 实干获取一手知识：普通人无需纠结高门槛领域，可从小需求试探开拓，在实干中积累专属的一手经验。
