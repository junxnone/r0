# 修身为基

> 朝闻道，夕死可矣。  
> 路漫漫，其修远兮。吾将上下而求索。

- 修身目的
- 如何修身
- 面对哪些问题？如何解决？


## 目的
为了看的更清，走的更远。
本来没有路，当你足够强大的时候就有了路。
就像曾经看到的那条科研路抽象图，初看，路越来越窄，再看那只是表象，其实是条条大路通罗马。

## 如何修身
以正在做的事情往外扩散是条好的路径。
毕竟花费时间最多，看到的可能更多，想法也才可能更深入。
